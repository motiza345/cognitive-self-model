# M29-D — Pre-Outcome Residual Predictor

M29-D is the design lock for the next scientific experiment.

It tests one preregistered hypothesis:

> local second-order curvature of the frozen mechanism response, measured before the scored intervention outcome, predicts the residual error of the first-order mechanism response.

Primary candidate:
\[
\kappa = \frac{\alpha^2}{2}F''(0)
\]

Primary baseline:
cell residual mean estimated only from UPDATE.

No Qwen scored execution is authorized until the synthetic gate passes.

## Non-goals

M29-D does not claim to build a complete self-model. It tests one necessary ingredient: whether an observable pre-outcome internal state can predict when a frozen mechanism response will be wrong.
