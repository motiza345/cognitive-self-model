# MRSM — Minimal Real Self-Model
## Implementation Specification + Cursor Master Instructions
### Version 1.0 — 2026-09-28

## 0. Purpose

Build a bounded, preregistered Go/No-Go benchmark for a Minimal Real Self-Model (MRSM).

This is NOT a continuation of M22.2 as an open-ended research milestone.
MRSM replaces M22.2 as the next scientific gate.

The purpose is to answer one question:

> Can the project construct a minimal self-model that captures causal mechanism information, predicts consequences of interventions, survives a representation change, and is actually consumed to improve a system decision?

The program has a hard budget:
- 4 calendar weeks
- maximum 8 full MRSM runs
- Planted arm P: CPU preferred
- Qwen arm Q: maximum 2 full runs
- CPU is default
- GPU for Q is permitted only if explicitly recorded in preregistration
- maximum 1 amendment per phase
- amendments may fix engineering defects only; they may NOT change scientific endpoints, thresholds, holdout membership, or gate definitions
- if budget expires with an unassessed gate: INCOMPLETE_BUDGET
- any continuation after the terminal decision requires a new DEC

# 2. Critical scientific correction: P vs Q ground truth

The benchmark has two arms.

## Arm P — Planted Transformer

A small transformer with deliberately planted, known mechanisms.

Properties:
- full mechanism ground truth
- known causal graph
- known intervention targets
- known mechanism identities
- known representation transformations

Purpose:
> Test whether the method actually works when the truth is known.

## Arm Q — Qwen2.5-0.5B

Real pretrained model.

Properties:
- no trusted mechanism ground truth
- same MRSM interface
- real model behavior

Purpose:
> Test whether the method transfers to a real LLM without pretending that unknown internal mechanisms are ground truth.

### Important rule

Do NOT use Qwen self-consistency, a discovery algorithm's own output, or a proxy label generated by the same pipeline as proof that the discovered mechanism is correct.

Therefore:

- P H1 is a hard correctness gate.
- Q H1 is diagnostic/structural evidence only unless an independently verified external ground-truth target exists.
- P H2/H3/H4 are hard gates.
- Q H2/H3/H4 are hard gates for the real-model claim.
- Q H1 must still be reported, but it must NOT be presented as verified mechanism identity.

This resolves the ground-truth contradiction in the earlier draft.

# 3. MRSM scientific definition

A system qualifies as a Minimal Real Self-Model only if it maintains an explicit representation of:

1. mechanism identity or mechanism hypothesis
2. causal relation between intervention and outcome
3. applicability/scope
4. prediction of intervention consequence
5. uncertainty/evidence trace
6. a machine-readable object that can be consumed by a decision policy

The Self-Model cannot be:

- a hidden neural predictor with no inspectable mechanism object
- a readout-only classifier
- a component-importance table
- a prompt embedding
- a scalar trust score
- an outcome memorizer

# 6. Planted arm P design

## 6.1 Model

Use a small PyTorch transformer designed for CPU execution.

Recommended starting point:

- vocab: synthetic
- sequence length: 16–32
- layers: 2
- heads: 4
- d_model: 64
- MLP width: 128
- deterministic seed
- no external pretrained weights

The model must be small enough for many CPU runs.

## 6.2 Planted mechanisms

At minimum create 3 mechanisms with deliberately distinct causal roles.

Example:

### M_COPY
A source token is copied through an attention path to a target position.

### M_INHIBIT
A feature/path suppresses another pathway under a defined context.

### M_BIND
A context-dependent binding relation determines which source controls a target.

The exact implementation can be adjusted during P2 design, but the ground-truth causal graph must be explicit and saved before P3.

## 6.3 Required ground-truth artifact

Create:

```text
artifacts/planted_ground_truth.json
```

It must contain:

- model hash
- seed
- mechanism IDs
- causal edges
- intervention targets
- expected qualitative effects
- expected quantitative effect ranges
- representation transformations
- holdout assignments

This file is immutable after preregistration.

# 9. H1 — Mechanism Discovery

## Scientific question

Can the system recover a mechanism on held-out data rather than merely memorize components or outcomes?

## Hard gate

P only.

## Primary endpoint

Mechanism recovery F1 on held-out mechanisms.

A mechanism is considered recovered only if:

1. the predicted mechanism maps to the correct planted mechanism;
2. the predicted causal direction matches ground truth;
3. the predicted effect sign matches ground truth on held-out interventions;
4. evidence trace exists for the claim.

## Proposed frozen threshold

H1-P PASS iff:

- mechanism F1 >= 0.80
- causal-edge precision >= 0.80
- false discovery rate <= 0.20

All three must pass.

No single favorable metric can compensate for another failing metric.

## Q arm

Q-H1 is reported descriptively only:

- number of candidate mechanisms
- reproducibility across seeds
- evidence completeness
- internal causal consistency

It is NOT called verified mechanism identity.

---

# 10. H2 — Counterfactual Prediction

## Scientific question

Before executing an intervention, can the Self-Model predict its consequence better than non-mechanistic baselines?

## Required baselines

1. readout-only
2. linear probe
3. cold-start
4. random-direction null

The primary comparator is the strongest preregistered non-self-model baseline.

## Primary endpoint

Paired intervention-level MAE.

## Proposed threshold

H2 PASS iff:

1. Self-Model MAE is at least 20% lower than the strongest non-self-model baseline;
2. the paired bootstrap 95% CI for MAE difference excludes zero in favor of Self-Model;
3. sign accuracy is >= 75%;
4. performance is measured only on held-out interventions.

No tuning on the test/holdout set.

---

# 11. H3 — Representation Invariance

## Scientific question

Is the learned mechanism represented independently of a particular coordinate system?

This directly targets the failure observed in M18.7/A4.

## Required transformation

Include the exact phase rotation:

```text
[X, Y] -> [Y, -X]
```

where applicable.

Also include at least one additional invertible transformation frozen before execution.

The transformation must preserve the underlying causal behavior while changing the representation coordinates.

## P endpoint

Mechanism identity agreement between canonical and transformed representation.

## Proposed threshold

H3-P PASS iff:

- identity agreement >= 90%
- causal effect sign agreement >= 90%
- counterfactual MAE degradation <= 10%

## Q endpoint

Because Q lacks mechanism ground truth:

H3-Q tests functional invariance:

- prediction agreement
- effect-sign agreement
- no material performance collapse after transformation

Q-H3 must not be described as proof of true mechanism identity.

---

# 12. H4 — Behavioral Utility / Consumption

## Scientific question

Does the Self-Model actually matter?

A model that is never consumed is not enough for S1.

## Required policy

The system receives a set of candidate interventions/actions.

The Self-Model predicts consequences.

The policy selects the action using those predictions.

## Required ablation

Run:

### Full
Self-Model is available and consumed.

### Consumption-ablation
Same Self-Model may exist internally, but the decision policy cannot access its predictions/mechanism output.

### Baseline policy
Simple non-self-model policy.

The action candidate set must be identical.

## Primary endpoint

Improvement in task utility / reduction in intervention damage relative to the consumption-ablation condition.

## Proposed threshold

H4 PASS iff:

- Full policy improves primary utility by >= 10% relative to consumption-ablation;
- paired bootstrap 95% CI excludes zero;
- the improvement occurs on held-out scenarios;
- the gain cannot be explained by additional compute or extra candidate information available only to Full.

This is the key distinction between:
> "we built a predictor"

and:
> "the system uses a self-model."

# 14. Leakage audit

The following are prohibited from inference-time input unless explicitly part of the allowed observation contract:

- planted mechanism labels
- ground-truth causal edges
- post-intervention outcome
- future evidence
- test/holdout labels
- ground-truth transformation identity
- hidden benchmark metadata

The model may receive only the same evidence available before the prediction/action.

Implement an automated leakage test.

# 24. P4 — Decision logic

Use exactly this decision tree.

## STOP

If H1-P fails.

Reason:
The proposed method cannot recover known mechanisms even when ground truth exists.

## REDEFINE

If:

- H1-P passes
- H2-P passes
- H3-P fails

Interpretation:
The system has some causal/predictive capability but is representation-dependent.

Retire the strong mechanism-identity claim.

## REDEFINE

If P passes but Q fails.

Interpretation:
The method works in controlled ground-truth conditions but does not currently scale/transfer to the real model.

A new bounded DEC is required before further Qwen work.

## GO

GO only if:

- P H1 passes
- P H2 passes
- P H3 passes
- P H4 passes
- Q H2 passes
- Q H3 passes
- Q H4 passes
- all preregistration and leakage audits pass

Q H1 remains diagnostic unless independent ground truth exists.

The next program must be scoped only to the capabilities actually supported by these results.

# 31. Why this benchmark is worth the remaining investment

The benchmark is deliberately small and adversarial.

It directly attacks the project's known failure modes:

- M6.8 → context dependence
- M18.7 → bad transfer
- A4 → coordinate dependence
- prediction-only false positives
- trust without evidence
- metric improvement without semantic validity
- recovery without mechanistic repair

Therefore MRSM is not another arbitrary milestone.

It is a concentrated test of whether the central research hypothesis survives contact with a controlled ground-truth benchmark and then a real LLM.
